## Computer Vision for Railway Safety

**Role:** ML Engineer · **Project:** RideOnTrack, for Infrabel (Belgian railway infrastructure) · **Period:** January – August 2025

## Overview

Inspecting railway tracks is slow and expensive. The RideOnTrack project used machine learning and computer vision to detect anomalies on Belgian railway tracks automatically, so that inspection can focus on the zones that need it.

## What I Built

- **Segmentation with U-Net** — isolates the track areas that matter in each image.
- **Anomaly detection with an autoencoder** — flags critical areas that differ from normal track, enabling targeted inspection.
- **Signal recognition with YOLOv8** — real-time train signal recognition, reaching 91% accuracy.

## Key Technologies

- **TensorFlow** — U-Net and autoencoder models
- **YOLOv8** — real-time object detection
- **AWS** — cloud environment for the project
